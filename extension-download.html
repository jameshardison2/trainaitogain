Step 2: Install via "Developer Mode"

1

Unzip the Folder

Find the downloaded get-you-hired-extension.zip file on your computer and extract/unzip it. You should now have a folder named extension.

2

Open Chrome Extensions

In your Chrome browser, type chrome://extensions into the URL bar and hit Enter.

3

Enable Developer Mode

In the top right corner of the Extensions page, toggle the switch that says "Developer mode" to the ON position.

4

Load Unpacked

Click the "Load unpacked" button that appeared in the top left. Select the unzipped extension folder you created in Step 1. That's it! The extension is now active.
