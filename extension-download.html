Install Your Application Assistant

Before you start your Mercor application, install the "Life Alert" assistant. If you get stuck or confused during the interview, click it to get instant help from your referral partner.

📥 Download Extension (.zip)

How to install it (Takes 30 seconds):

1

Extract the ZIP file

Find the get-you-hired-extension.zip file in your downloads folder. Double-click it (Mac) or Right-Click and select "Extract All" (Windows) to unzip it into a folder.

2

Open Chrome Extensions

Open a new tab in Chrome and copy/paste this URL into the address bar:

chrome://extensions/
3

Load Unpacked

In the top right corner, turn on "Developer mode". Then click the "Load unpacked" button in the top left and select the folder you unzipped in Step 1.

✅ Success! You will see the "Mercor App Assistant" icon appear in your Chrome toolbar.
